## 📸 Automatic Photo Workflow

The project includes an automated image optimization workflow.

### How to add a new photo

1. Open the repository.
2. Go to the `assets/` folder.
3. Upload your JPG, JPEG, PNG, BMP or TIFF image.
4. Commit the changes to the `main` branch.
5. GitHub Actions automatically starts the optimization workflow.
6. The image is converted to **WebP**.
7. The original raster image is removed.
8. `gallery-data.js` is automatically regenerated.
9. The optimized image becomes available in the website gallery.
